PrimeLend Admin Dashboard + SQLite Database

HOW TO RUN
1. Install Node.js 20 or newer.
2. Extract this ZIP.
3. Open Command Prompt / Terminal inside the extracted folder.
4. Run: npm install
5. Run: npm start
6. Open http://localhost:3000
